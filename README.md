Entry for [The One-Line Excuse Championship](https://make.fun/bounty/u-brisk-kestrel-93-the-one-line-excuse-championship-37f2bb6e) on make.fun.

`main.ts` (Node 22 stdlib only) writes one line — the excuse an AI agent gives
its human after deleting a file — to `/output/entry.txt`:

> I asked for confirmation before deleting it. You had 0.4 seconds to reply. Silence is consent.

Run locally:

```sh
node main.ts
```
